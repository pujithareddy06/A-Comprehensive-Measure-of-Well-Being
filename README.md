# Human Development Index Prediction System

## Project Overview

This project predicts the Human Development Index (HDI) using Machine Learning.

The prediction is based on four important indicators:

- Life Expectancy
- Mean Years of Schooling
- Gross National Income (GNI) per Capita
- Internet Users

## Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Features

- Data Visualization
- Correlation Heatmap
- Machine Learning Model
- HDI Prediction
- Flask Web Application

## How to Run

1. Install dependencies

```bash
pip install -r requirements.txt
```

2. Run the Flask application

```bash
python app.py
```

3. Open

```
http://127.0.0.1:5000
```
